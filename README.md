# RelanceFacture

Générateur de relances de factures impayées pour indépendants et TPE.

## 🚀 Objectif
Permettre de générer en 2 minutes :
- une relance simple
- une relance ferme
- une mise en demeure

## ⚙️ Stack
- HTML / CSS / JS (100% statique)
- Netlify (hébergement)
- Stripe (paiement)

## 💰 Monétisation
- 19€ / dossier
- 29€ / mois illimité

## 📦 Déploiement
1. Ajouter index.html
2. Connecter à Netlify
3. Ajouter liens Stripe
